# Unemployment Analysis with Python

## Project Overview
This project analyzes unemployment data in India using Python.

## Objective
- Analyze unemployment rate by state.
- Analyze monthly unemployment trends.
- Visualize the data using graphs.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Dataset
Unemployment_Rate_upto_11_2020.csv

## Outputs
- output1.png
- output2.png
- output3.png

## How to Run

```bash
pip install pandas matplotlib seaborn
python unemployment_analysis.py
```
